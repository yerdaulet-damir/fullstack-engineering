# Launch Page Starter

A dependency-free product launch page built with semantic HTML, CSS, and browser JavaScript.

## Run

```bash
npm start
```

Open `http://localhost:3001`. Run `npm test` for all checks or `npm run check:starter` for the starter contract.

The page works now. The marked `TODO` items are the learner exercises, not setup failures.

## Open while building

- [MDN Learn Web Development](https://developer.mozilla.org/en-US/docs/Learn_web_development) for semantic HTML, CSS, forms, and browser JavaScript.
- [web.dev Learn CSS](https://web.dev/learn/css/) for layout and responsive behavior.
- [MDN accessibility](https://developer.mozilla.org/en-US/docs/Learn_web_development/Core/Accessibility) for keyboard, focus, labels, and media checks.
- [web.dev Learn Performance](https://web.dev/learn/performance/) when measuring LCP, CLS, and resource loading.
