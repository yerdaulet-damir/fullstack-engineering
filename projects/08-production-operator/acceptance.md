# Acceptance

- Workflow states and allowed transitions are explicit.
- Read tools can run during investigation; write tools require an approval record.
- Approval shows evidence and the exact side effect.
- Replaying a completed execution key returns the recorded result.
- Serialized workflow state resumes after process restart.
- Tool schemas and permissions live outside prompt text.
- CI includes types or syntax, tests, dependency audit, and eval regression.
- A runbook covers provider outage, cost spike, bad release, and rollback.
