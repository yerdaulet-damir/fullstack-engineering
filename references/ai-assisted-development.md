# AI-assisted development references

These sources support a disciplined coding loop. Tool-specific commands will change; task definition, review, tests, and runtime evidence remain useful.

- [GitHub Copilot code review](https://docs.github.com/en/copilot/concepts/agents/code-review) — capabilities, costs, limitations, and the requirement to validate generated feedback.
- [GitHub Copilot coding agent](https://docs.github.com/en/copilot/using-github-copilot/coding-agent) — issue-to-pull-request workflow and repository controls.
- [Claude Code common workflows](https://docs.anthropic.com/en/docs/claude-code/common-workflows) — inspect, plan, test, and work with existing repositories.
- [OpenAI Codex documentation](https://developers.openai.com/codex/) — coding-agent setup and workflows.
- [Google Engineering Practices: code review](https://google.github.io/eng-practices/review/) — judge the change, not the confidence of the author or agent.
- [OWASP Secure Coding Practices](https://owasp.org/www-project-secure-coding-practices-quick-reference-guide/) — a compact review baseline for generated code.

The repository's required loop is in [`playbook/ai-assisted-development.md`](../playbook/ai-assisted-development.md). It is intentionally tool-neutral.
