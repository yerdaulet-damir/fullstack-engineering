# Backend and data references

## HTTP and APIs — project 03

- [MDN HTTP overview](https://developer.mozilla.org/en-US/docs/Web/HTTP/Overview) — request/response semantics, methods, status codes, caching, and intermediaries.
- [HTTP Semantics](https://www.rfc-editor.org/rfc/rfc9110) — normative reference when behavior is ambiguous.
- [Fastify documentation](https://fastify.dev/docs/latest/) — routes, schemas, plugins, logging, testing, and graceful shutdown.
- [OpenAPI Specification](https://spec.openapis.org/oas/latest.html) — machine-readable HTTP contracts.

## PostgreSQL — projects 03–08

- [PostgreSQL tutorial](https://www.postgresql.org/docs/current/tutorial.html) — SQL and relational basics.
- [Transactions](https://www.postgresql.org/docs/current/tutorial-transactions.html) — all-or-nothing multi-step changes.
- [Indexes](https://www.postgresql.org/docs/current/indexes.html) — index types, cost, and query planning.
- [Using EXPLAIN](https://www.postgresql.org/docs/current/using-explain.html) — measure a query before adding an index.
- [Row security policies](https://www.postgresql.org/docs/current/ddl-rowsecurity.html) — optional defense in depth for tenant data.

## Security and tenancy — projects 04 and 06

- [OWASP Authorization Cheat Sheet](https://cheatsheetseries.owasp.org/cheatsheets/Authorization_Cheat_Sheet.html) — server-side, deny-by-default authorization.
- [OWASP Session Management Cheat Sheet](https://cheatsheetseries.owasp.org/cheatsheets/Session_Management_Cheat_Sheet.html) — session identifiers, cookies, expiry, and invalidation.
- [OWASP File Upload Cheat Sheet](https://cheatsheetseries.owasp.org/cheatsheets/File_Upload_Cheat_Sheet.html) — validation and storage boundaries.
- [OWASP REST Security Cheat Sheet](https://cheatsheetseries.owasp.org/cheatsheets/REST_Security_Cheat_Sheet.html) — API-specific threats and controls.
