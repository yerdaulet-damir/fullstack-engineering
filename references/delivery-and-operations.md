# Delivery and operations references

## Containers and CI — projects 03–08

- [Docker Get Started](https://docs.docker.com/get-started/) — images, containers, Compose, and development workflow.
- [Docker build best practices](https://docs.docker.com/build/building/best-practices/) — deterministic, cacheable, smaller images.
- [GitHub Actions](https://docs.github.com/en/actions) — workflows, jobs, caching, environments, and secrets.
- [GitHub secure use reference](https://docs.github.com/en/actions/security-for-github-actions/security-guides/security-hardening-for-github-actions) — pinning actions, untrusted input, permissions, and credentials.

## Production behavior — projects 06–08

- [OpenTelemetry overview](https://opentelemetry.io/docs/what-is-opentelemetry/) — traces, metrics, and logs without choosing a monitoring vendor.
- [The Twelve-Factor App](https://12factor.net/) — useful operational baseline; apply judgment to modern platforms.
- [Google SRE: Monitoring Distributed Systems](https://sre.google/sre-book/monitoring-distributed-systems/) — signals and alerts tied to user-visible failure.
- [Google SRE: Handling Overload](https://sre.google/sre-book/handling-overload/) — capacity, backpressure, and graceful degradation.
- [Cloudflare Workers documentation](https://developers.cloudflare.com/workers/) — one low-cost edge deployment option.
- [Vercel documentation](https://vercel.com/docs) — one managed deployment option for the full-stack projects.
