# Web and frontend references

Read these when a project requires them. Do not read the whole list before building.

## Foundations — project 01

- [MDN Learn Web Development](https://developer.mozilla.org/en-US/docs/Learn_web_development) — semantic HTML, CSS, JavaScript, accessibility, and browser fundamentals.
- [MDN accessibility](https://developer.mozilla.org/en-US/docs/Learn_web_development/Core/Accessibility) — use while checking navigation, forms, focus, and media.
- [web.dev Learn Performance](https://web.dev/learn/performance/) — use when measuring LCP, CLS, resource loading, and responsiveness.
- [WAI-ARIA Authoring Practices](https://www.w3.org/WAI/ARIA/apg/) — interaction and keyboard patterns for widgets. Prefer native HTML before adding ARIA.

## TypeScript and React — project 02

- [TypeScript Handbook](https://www.typescriptlang.org/docs/handbook/) — narrowing, object types, modules, and compiler behavior.
- [React: Thinking in React](https://react.dev/learn/thinking-in-react) — split a UI by data and ownership rather than arbitrary components.
- [React: You Might Not Need an Effect](https://react.dev/learn/you-might-not-need-an-effect) — avoid using effects for derived state and event handling.
- [Vite guide](https://vite.dev/guide/) — development/build behavior for the dashboard starter.
- [Testing Library guiding principles](https://testing-library.com/docs/guiding-principles/) — test the application through user-visible behavior.

## Full-stack React — project 04

- [Next.js App Router](https://nextjs.org/docs/app) — routing, server/client boundaries, data access, metadata, and deployment.
- [MDN React accessibility](https://developer.mozilla.org/en-US/docs/Learn_web_development/Core/Frameworks_libraries/React_accessibility) — focus management and accessible behavior in a React application.
- [Web Content Accessibility Guidelines 2.2](https://www.w3.org/TR/WCAG22/) — normative reference for acceptance decisions.
